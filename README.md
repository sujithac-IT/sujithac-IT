### 1. [Cognexis — AI-Powered EV Battery Intelligence & Digital Twin Platform](https://github.com/sujithac-IT/DigitalTwin)
*An integrated hardware-to-cloud telemetry and digital twin platform monitoring electric vehicle battery pack parameters in real time.*

[![Digital Twin Repo](https://img.shields.io/badge/Repository-DigitalTwin-0A66C2?style=flat-square&logo=github)](https://github.com/sujithac-IT/DigitalTwin)
[![Route Planner Repo](https://img.shields.io/badge/Repository-ev--route--planner-0A66C2?style=flat-square&logo=github)](https://github.com/sujithac-IT/ev-route-planner)
[![Live Demo](https://img.shields.io/badge/Demo-digital--twin--flame.vercel.app-0284c7?style=flat-square&logo=vercel)](https://digital-twin-flame.vercel.app)
[![Achievement](https://img.shields.io/badge/Recognition-EDII--TN%20IVP%20Selected-0e7490?style=flat-square)](https://github.com/sujithac-IT/DigitalTwin)

* **Architecture Overview:** An embedded sensor rig mounted to a 12 V pack captures real-time physical metrics and streams them over Wi-Fi to a FastAPI cloud service at 1 Hz, which populates a live 3D web dashboard with interactive telemetry and route awareness.
* **Current Status:** Functional hardware-and-software prototype developed; currently advancing toward enhanced edge intelligence and validation under the **EDII-TN Innovation Voucher Programme (IVP)**.

```
 [ESP32 Hardware Rig]                     [FastAPI Cloud Service]                 [React + Three.js Web Client]
 ├─ Voltage Divider (Pack Voltage)  ───┐   ├─ REST Telemetry Ingestion (1 Hz) ──>  ├─ 3D Vehicle Model (Three.js)
 ├─ ACS712 Sensor (Current Draw)    ───┼──>├─ SQLAlchemy Pack State History        ├─ Live Battery Telemetry Gauges
 ├─ DHT11 Sensor (Pack Temperature) ───┤   ├─ JWT-Guarded Access Endpoints         ├─ OpenStreetMap Charger Map (Leaflet)
 ├─ GPS Module (TinyGPSPlus via UART)──┤   └─ Alert Event Dispatcher               └─ Automated Emergency Alert Log
 ├─ SIM800L (Automated SMS over GSM) ──┘
 └─ 20x4 I2C LCD (Local Readout)
```

| Lifecycle Stage | Features & Technical Details |
| :--- | :--- |
| **🟢 Implemented Prototype** | • Multi-sensor data acquisition reading voltage, current (100-sample averaging), and temperature.<br/>• Standalone hardware fail-safe: automated SMS with GPS coordinates via SIM800L if temperature exceeds 35°C.<br/>• Local status readout on 20x4 I2C LCD and hardware LED indicators.<br/>• FastAPI telemetry backend streaming data at 1 Hz with historical database storage.<br/>• Interactive web dashboard built with React, Three.js 3D car rendering, and Leaflet EV charger discovery using OpenStreetMap data. |
| **🟡 Under Active Development** | • Integration of Raspberry Pi for edge telemetry aggregation and local data buffering.<br/>• Refined State of Charge (SOC) tracking algorithms based on continuous coulomb-counting heuristics.<br/>• Early anomaly detection filters to identify sudden voltage sags and abnormal thermal spikes. |
| **🔵 Future Plans & Roadmap** | • State of Health (SOH) degradation modeling and cycle-life estimation.<br/>• Machine learning models for predictive thermal runaway early warnings.<br/>• Dynamic range estimation integrated with route elevation and driver behavior.<br/>• Multi-pack laboratory bench testing under controlled discharge profiles. |

* **Technologies:** `ESP32` · `C++ / Arduino` · `FastAPI` · `Python` · `React.js` · `TypeScript` · `Three.js` · `Leaflet.js` · `SQLAlchemy` · `Docker`

### 2. [MedTrust AI — AI-Assisted Clinical Documentation & Telehealth Platform](https://github.com/sujithac-IT/medtrustAI)
*A role-based telehealth consultation and clinical documentation application designed for teaching hospital workflows.*

[![MedTrust Repo](https://img.shields.io/badge/Repository-medtrustAI-0A66C2?style=flat-square&logo=github)](https://github.com/sujithac-IT/medtrustAI)
[![Live Demo](https://img.shields.io/badge/Demo-medtrust--ai--two.vercel.app-0284c7?style=flat-square&logo=vercel)](https://medtrust-ai-two.vercel.app)
[![Testing](https://img.shields.io/badge/Test%20Suite-pytest%20Passing-16a34a?style=flat-square&logo=pytest)](https://github.com/sujithac-IT/medtrustAI)

* **Architecture Overview:** Connects doctors, medical students, and patients via encrypted peer-to-peer WebRTC video channels. Doctor-patient conversations are transcribed in real-time, and Google Gemini extracts structured data into an editable 17-section clinical case-sheet that is reviewed and electronically locked by the attending physician.
* **Key Technical Implementations:**
  * **Real-Time Communication:** Mesh WebRTC peer-to-peer video streaming, WebSocket signaling channels, waiting lobby, and real-time audio caption streaming via Web Speech API.
  * **AI-Assisted Case-Sheet Extraction:** Structured prompt engineering with Google Gemini API to extract symptoms, vitals, history, and provisional diagnoses into standard medical templates.
  * **Offline / Fault-Tolerant Fallback:** Includes a grounded rule-based local extractor so that case-sheet drafting functions reliably even when API credentials are absent or network connectivity drops.
  * **Role-Based Access Control (RBAC):** Distinct permission tiers for Doctors, Medical Students, and Patients enforced via JWT auth tokens, rate-limited login endpoints, and strict Content Security Policies (CSP).
  * **Integrity & Security:** Electronic signature workflow that permanently locks case records post-signing to prevent tampering.
  * **Engineering Rigor:** Automated SQLite schema migrations, horizontal scaling support via PostgreSQL and Redis pub/sub, Docker Compose multi-container setup, and an automated `pytest` suite testing API endpoints and WebSocket lifecycles.
* **Technologies:** `React 18` · `Vite` · `FastAPI` · `Python` · `WebRTC` · `WebSockets` · `Google Gemini API` · `SQLite / PostgreSQL` · `Docker` · `pytest`
* *Disclaimer:* MedTrust AI is an engineering project built for educational, training, and workflow demonstration purposes. It does not possess medical device certification, and AI-generated case sheets must be clinically audited by a licensed healthcare professional.
